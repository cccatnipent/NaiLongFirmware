# 快速开始：设备连接自己的小智后端

## 1. 准备

- 同型号四舵机机器人：ESP32-S3、16MB Flash、8MB PSRAM、ST7789 240×240，无手臂/摄像头。
- 固件终端：ESP-IDF **5.5.5**。Windows 在 ESP-IDF PowerShell 中操作，Linux/macOS 先加载该版本 export 脚本。
- 后端终端：独立 Python **3.10** 环境。按照随包 `xiaozhi-esp32-server/docs/Deployment.md` 安装依赖、libopus 和 ffmpeg。
- 电脑和机器人接入同一局域网。下面 `192.168.1.20` 仅是示例，替换为电脑可被机器人访问的地址。
- 选择支持流式工具调用的模型，准备其 API base URL、模型名和自己的密钥。`type: openai` 在此表示兼容的接口格式，可以连接相应格式的模型服务。

固件环境和后端环境分开使用，避免给 ESP-IDF 的 Python 环境安装 torch 等后端依赖。

## 2. 生成后端配置

在课程根目录运行。此脚本只需要 Python 和 PyYAML；ESP-IDF 环境若已带 PyYAML 可直接执行。

```powershell
python -m pip install PyYAML
python scripts/configure_backend.py --host 192.168.1.20
```

它创建 `xiaozhi-esp32-server/main/xiaozhi-server/data/.config.yaml`，写入局域网 WebSocket 地址、课程人设和随机认证密钥。已有文件时会退出，不覆盖学生配置。

打开生成的文件，在 `LLM.CourseLLM` 填好 `base_url`、`model_name`、`api_key` 三项 `YOUR_*` 占位符。也可通过 `--base-url`、`--model` 和环境变量 `NAILONG_LLM_API_KEY` 生成；环境变量的值不会打印。先在自己的终端设置该变量，不把真实密钥写入课程文档或提交记录。

课程默认选择：SileroVAD、本地 FunASR/SenseVoiceSmall、兼容接口 LLM、EdgeTTS、function_call。EdgeTTS 和远程模型需要联网；“本地后端”不代表全部计算离线。完全离线课程需另选本地模型和 TTS。

## 3. 启动后端

切换到已安装依赖的 Python 3.10 后端环境：

```powershell
cd xiaozhi-esp32-server/main/xiaozhi-server
python -m pip install -r requirements.txt
python app.py
```

首次运行前按上游 `docs/Deployment.md` 的“模型文件”章节准备 SenseVoiceSmall 权重，放到 `models/SenseVoiceSmall/model.pt`。随包仅含源码/模型元数据，未包含大型权重。ffmpeg 和 libopus 也需可被此环境访问。

日志中应出现 HTTP `8003` 和 WebSocket `8000` 服务。电脑防火墙需允许局域网设备访问这两个端口。入门模式不需要 MySQL、Redis 或 Java 管理 API。

在另一个终端、课程根目录检查发现接口：

```powershell
python scripts/probe_ota.py http://192.168.1.20:8003/xiaozhi/ota/
```

返回的 `websocket_url` 必须是机器人可访问的地址。脚本使用虚构探测设备，不修改真实机器配置，输出隐藏 token。

## 4. 编译和烧录固件

切回 ESP-IDF 5.5.5 终端：

```powershell
cd nailong-firmware
python scripts/build_nailong.py --ota-url http://192.168.1.20:8003/xiaozhi/ota/
idf.py -p COM3 flash monitor
```

首次构建会下载依赖组件和语音资源，耗时取决于网络。COM3 按机器实际串口替换。素材已准备好，首次构建不需要重新运行 ffmpeg 转换。

该命令针对同型号硬件生成程序、分区和素材；正常 `idf.py flash` 按各分区地址烧录，不是整片擦除。已有设备升级时先核对分区表，保留配置的写法见下一章。

在设备配网页填入 Wi-Fi。如果设备以前在配网页保存过自定义 OTA 地址，NVS 的 `wifi/ota_url` 优先于编译默认值：在配网页把它改为本课程地址。无需为改后端而整片擦 NVS 或清舵机校准。

设备开机经 HTTP OTA 获取 WebSocket 地址和 token，再连语音服务；单服务模式的人设来自本地 `.config.yaml`，不需要去 xiaozhi.me 绑定账号。

## 5. 课堂验收

说“你好奶龙”，再测试问答图片、字幕/电量/网络、“笑一个”、往前走和“边笑边走”。组合请求应调用 `self.otto.laugh_walk`，不能依次调用 laugh 和 action 来假装并行。

语音“停下”只停止动作；BOOT 打断本轮音频和动作后应继续监听。记录串口和服务端日志；课程源码的自动测试不能代替同型号真机验收。

## 使用 xiaozhi.me

若先学习云端使用，在固件目录执行不带 `--ota-url` 的 `python scripts/build_nailong.py`，编译默认地址为官方 OTA。若配网页保存了自定义地址，需同步改回。将 `persona.txt` 复制到自己的后台人设，按正常设备激活流程绑定。
